Tab to TV privacy policy

Last updated: November 11, 2026

Tab to TV is a Chrome extension for classroom use. It lets a teacher show one browser tab on a classroom TV or external display and pause that picture.

What it accesses

  • The title and icon of browser tabs, so it can show which tab is on the TV.
  • A live video of the one tab the teacher chooses to show (video only, no tab audio).
  • Display information (screen names, sizes and layout), so it can find the TV and put the picture on the correct screen.

How it uses that information

It uses this information only to provide those features on the same Chromebook. The live picture is shown fullscreen on the external display. When the teacher pauses a live tab, the last frame is held so students keep seeing a still picture. When the teacher pauses without showing a tab, the TV shows a pause screen that is built into the extension; nothing on the teacher's screen is captured. Tab titles and icons appear in the extension panel.

What it shares

It does not send this information to the developer, to Daviess County Public Schools servers, or to any other party. It does not include analytics, advertising, or remote code.

Where it is stored

Everything stays on the Chromebook and is not synced to a Google account. The live picture is never saved. Information about what is currently showing is kept in Chrome session storage and is cleared when the teacher stops showing, uses Stop everything, or ends the browser session.

If the teacher picks which screen is the TV, the extension remembers that choice (the screen's name and resolution) in Chrome local storage on that Chromebook, so it can pick the same TV next time. Only the most recent choices are kept, and they are removed when the extension is removed.

Limited use

Tab to TV uses this information only to provide its single purpose: showing one tab on the classroom TV and pausing it. It does not use the information for advertising or retargeting, and it does not transfer it to others except as required by law.
